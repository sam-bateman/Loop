# Loop brand assets

**Everything here is the one part of the design that is _not_ disposable scaffolding.**
The rest of the UI is meant to be rethought (see the root `README.md`); this wordmark is
the brand direction.

## The wordmark

`loop-wordmark.jpg` is the source Owen supplied. Every other file is derived from it by
`scripts/brand/generate.mjs` — run `npm run brand` to regenerate.

The source is a JPEG, which is the wrong format for a logo: it carries compression
artifacts and a soft glow halo. The generator rebuilds each asset as a lossless PNG,
taking alpha from the green channel (with the halo floored off) and flattening colour to
the exact brand green. If a true vector is ever drawn, replace the source and delete the
generator.

| File | Use |
|---|---|
| `loop-wordmark.png` | Primary wordmark, transparent background |
| `loop-wordmark-black.png` | Wordmark on Loop black, 1024² — decks, social |
| `loop-mark.png` | The infinity mark alone, transparent |
| `loop-icon-1024.png` | **App icon** — the full wordmark. Uploaded to WHOOP |
| `loop-icon-512.png` / `-180.png` | Smaller icon sizes |
| `loop-markicon-512.png` / `-180.png` | Mark-only square, for spots too small for four letters |
| `loop-wordmark.jpg` | Source of truth — do not edit derived files by hand |

`app/icon.png` and `app/apple-icon.png` (favicons) are generated by the same script.

## Colour

| Token | Value | Notes |
|---|---|---|
| Brand green | `#40F830` | Sampled from the wordmark — the dominant pixel value |
| Loop black | `#0A0A0B` | `--bg` |

The brand green doubles as the **"life gained"** colour in the scoring UI, with
`#FF6B52` for life lost. That is deliberate: gaining time *is* the brand, so the
product's best outcome renders in the brand colour and nothing else competes with it.

## The mark

The two `o`s form a lemniscate — a closed loop with no endpoint. It reads as both the
product name and the thing the product is about.

**The app icon uses the full wordmark, not the mark alone.** On WHOOP's pairing and
consent screens the icon sits directly beside the WHOOP logo, and an infinity symbol on
its own reads as a generic infinity symbol — it loses the name at exactly the moment a
user is deciding whether to trust us with their data. `loop` stays legible down to
180px, which is the smallest size WHOOP renders. The mark-only squares
(`loop-markicon-*.png`) exist for anywhere genuinely too small for four letters; the
32px favicon is the only place currently using one.
